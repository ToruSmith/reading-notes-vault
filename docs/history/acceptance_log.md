# P3 批次二：雙語、主題、圖庫與日曆（驗收）

## 新功能
- **三種檢視**：列表｜圖庫｜日曆（筆記列表上方的分頁）。日期範圍與排序同時作用於列表和圖庫。
- **圖庫**：有 `cover` 的筆記顯示 SVG 縮圖（捲到才載入），沒有就顯示標題首字。

6. 靜態畫布為簡化唯讀版（無影片嵌入）。沒有 `lang` 的筆記歸中文。靜態搜尋是標題／標籤／主題／摘要的子字串比對。英文介面翻譯未經人工校對。
7. 批次刪除沒有復原或垃圾桶檢視。額度數字（Apps Script、GitHub、Cloudflare）請以官方文件為準，會變動：
   - Apps Script 配額：https://developers.google.com/apps-script/guides/services/quotas
   - GitHub Git trees：https://docs.github.com/en/rest/git/trees
   - Cloudflare Pages 限制：https://developers.cloudflare.com/pages/platform/limits/

## 四、手動驗收步驟（按鈕名稱：預覽變更＝預演）
**A. 部署（不需再執行 setupVault）**
1. 把 `Vault_all.gs` 內容貼進 Apps Script 取代舊檔；`index.html` 貼進 `index`。
2. 編輯器執行 `authorizeP5()` → 授權。
3. 兩個部署各「新版本」。

**B. 備份**
4. 開「同步與備份」→「立即備份」，跑完顯示檔名與數量。到 Drive 的 `_backup` 資料夾，下載 ZIP 解壓，確認有 notes/、assets/、topics/、boards/、manifest.json。用「備份」頁的還原預覽打開該 ZIP，數量應一致。
5. 開「每月自動備份」，確認狀態顯示下次時間。

**C. GitHub 與靜態站**
6. 建私人 repo（需先有一次提交，例如勾選 README）。
7. 建細粒度權杖：只限該 repo，Contents 設 Read and write。
8. 指令碼屬性新增：`GITHUB_TOKEN`、`GITHUB_REPO`（`owner/repo`）；可選 `GITHUB_BRANCH`（預設 main）、`GITHUB_DIR`（預設 content）、`BACKUP_KEEP`、`PUBLIC_URL`。
9. 把 `vault-site-template.zip` 解開，`site/` 內的檔案放到 repo 根目錄並提交。
10. Cloudflare Pages 連接 repo：Build command `node build.js`，output `dist`，環境變數 `SITE_URL`，必要時 `NODE_VERSION=20`。
11. 同步頁按「預覽變更」看將變動數量，再按「立即同步」。repo 應出現 `content/`，Pages 自動建置。
12. 開 `/zh/`、`/en/`：筆記、主題、畫布、搜尋可用；私人筆記不存在。比對筆記數與 GAS 訪客視角一致。
13. 再按一次同步，應顯示「沒有變動」且不新增提交。

## 一、完成清單
1. **筆記卡片更豐富**：顯示日期、標籤（最多 4 個）、封面 SVG 縮圖，內文摘要照舊。
2. **連結卡片預覽**：
   - 加入連結時（擁有者），由 Apps Script 代抓一次網頁的標題、描述、封面圖網址、站名，存進卡片的 `x-preview`；之後開畫布不再連網。
   - 卡片右側面板有「擷取預覽／重新擷取／移除預覽」。
   - YouTube：預覽圖開啟時顯示縮圖，仍是按了才載入影片。圖片網址：預覽圖開啟時直接顯示成圖。
3. **預覽圖開關**（每位檢視者自己決定，預設關閉）：工具列「預覽圖：開／關」。關閉時不會連任何外部網站；開啟時才會載入縮圖。
4. **SVG 圖片卡**：工具列「＋圖片」，從筆記引用或當封面的 SVG 挑選放進畫布。
5. **整理排版**：工具列「整理排版」，三種方式：網格（依日期）、依標籤分組、依月份時間軸；可選「也放入本主題還沒上畫布的筆記」；有選取卡片時只整理選取的；可復原；按「儲存」才寫入。
6. **靜態站**：畫布的連結卡片顯示預覽的標題、描述與站名（純文字）；靜態站不載外部縮圖。

## 二、驗收標準對照
| 標準 | 結果 |
| --- | --- |
| 預設不連任何外部網站 | 自動測試：預設狀態開啟畫布，外部請求數為 0；開啟預覽圖後才出現 YouTube 縮圖等請求 |

## 三、已知限制
1. **擷取預覽需要授權**：第一次要在編輯器執行 `authorizeP5()`（若之前做過就已經有）。沒授權時擷取會失敗，卡片仍會加入。
2. 後端代抓只讀前 300 KB、當成 UTF-8；少數舊網站（Big5 等）標題可能亂碼；需要登入、擋機器人或用 JavaScript 才產生預覽資訊的網站會抓不到。
3. 網址檢查擋 http、IP、連接埠、帳密、內網名稱；但不能防範「公開網域名稱被指到內網位址」或網站轉址到其他網站。這個功能只由擁有者觸發、只回純文字，且 Apps Script 是在 Google 的伺服器上連線，不在你的內網。
4. 預覽是加入當下的快照，不會自動更新；要更新請按「重新擷取預覽」。
5. 預覽圖開啟時，Apps Script 網頁框架是否允許載入外部圖片，我無法在真實環境驗證，請看手動步驟 6。
6. 整理排版只重排筆記與圖片卡片，文字與連結卡片不動，位置可能與它們重疊，需要自己微調。
7. 手機上畫布預設只能閱讀，「整理排版」「擷取預覽」等編輯功能在手機不可用。

## 四、手動驗收步驟

2. 開某個主題的畫布，放幾張筆記卡片：應看到日期、標籤，有封面的筆記有縮圖。
3. 「＋連結」貼一個新聞或部落格網址（https），保持勾選「加入後擷取網頁預覽」→ 加入。幾秒後卡片出現標題與描述。按「儲存」，重新整理後仍在。
4. 貼一個 YouTube 網址：預設是「▶ 載入影片」按鈕，沒有縮圖；按工具列「預覽圖：關」改成開，應出現縮圖。再按一次關閉，縮圖消失。
5. 「＋圖片」→ 選一張 SVG → 畫布出現圖片卡。

9. 靜態站：同步後開 `/zh/board/<主題>/`：連結卡片顯示預覽標題與描述。

## 步驟
1. 畫布 ＋新增 →「HTML 檔」，選一個你的 .html（或把檔案拖進畫布）。卡片只顯示標題與「▶ 載入 HTML」。
2. 按載入：頁面靜態顯示（腳本不會執行）。按卡片上的「互動」才能在裡面捲動；平常拖曳／縮放畫布不會被卡住。
3. 選取卡片，右側勾「允許執行腳本」→ 卡片回到載入鈕 → 再載入，腳本才會執行。按「儲存」。
4. 連結卡片選取後勾「嵌入網頁」，貼 GitHub Pages 網址 → 按「▶ 嵌入網頁」。若畫面空白＝該站不允許嵌入，按「↗」另開分頁。
4b. HTML 卡片上**雙擊**或按「↗」：新分頁開成完整頁面；**右鍵**有「在新分頁開啟」「下載 .html」。
5. 一次載入 4 個以上：最舊的會自動收回成按鈕（最多 3 個同時載入）。
6. 訪客（無痕視窗）開公開畫布：看得到卡片，按載入可顯示。
7. 備份 ZIP 內有 `assets/<id>.html`；還原時會一併帶回。
8. **請在手機實測一次**（Apps Script 頁面本身在 iframe 內，是兩層 iframe）。
