# 更新與驗收（精簡版）

只要做這 4 件事，之後的驗收都照這個流程。

1. **換成單一檔案**（現在改成只貼一次）：
   - 在專案裡把 `Core`、`Store`、`Svg`、`Yaml` 四個檔案**刪除**（檔名右邊「⋮」→「刪除」）。
   - 把 `Code` 檔案的內容**全選刪光**，貼上 `Vault_all.gs` 的全部內容，存檔。
   - 最後專案裡只剩 `Code` 一個檔案。指令碼屬性與資料都在，不會消失。
   - 若編輯器因檔案太大（約 97 KB）拒絕貼上，請告訴我，我改回分檔並做更不容易貼錯的版本。
2. **執行一次自我檢查**：上方函式選 `devSelfCheck`，按「執行」。
   - 看「執行記錄」最後一行。顯示「自我檢查：N 項通過，0 項失敗」就完成。
   - 若有失敗，會列出是哪幾項，把那幾行告訴我就好。
3. **更新兩個部署**（這是 C2、C3 失敗的原因）：
   「部署」→「管理部署作業」→ 點某個部署右邊的鉛筆 → 「版本」選「新版本」→ 「部署」。
   讀取部署與編輯部署**各做一次**。網址不會變。
4. **把讀取網址貼給我**。網頁那一層（無痕視窗該測的項目）由我用網址測，你不用再開無痕視窗。

## 自我檢查涵蓋什麼

示範資料、重複執行不產生重複檔、訪客視角不外洩（含標題、內文、id、檔名、主題名）、私人 SVG 與不存在無法區分、清空索引後可由 Drive 重建且完全一致、筆記是一般檔案而非 Google 文件、SVG 已清除腳本、主題改公開需確認。

## 這個流程沒涵蓋什麼

- 網頁部署是否跑新版本：由我用你貼的網址測。
- 手機登入與編輯：等前端完成後才有東西可測，屆時我會把手機驗收壓到最少步驟。
