## 1. 事前準備與運作原理

**需要**：一個 Google 帳號、電腦瀏覽器（Chrome 最佳）。不需要信用卡，不需要安裝任何軟體。

**運作原理**：
- 你的筆記存在 Drive 的 `Vault/` 資料夾，是一般檔案：`notes/*.md`、`assets/*.svg`、`topics/*.json`、`boards/*.canvas.json`。
- 一張 Google 試算表「Vault 索引」只是目錄，壞了可以重建。
- 同一份程式發佈成**兩個網址**：
  | | 讀取網址 | 編輯網址 |
  | --- | --- | --- |
  | 給誰 | 任何人（訪客） | 只有你 |
  | 看到什麼 | 只有你標為公開的內容 | 全部，可新增、編輯、刪除 |
  | 是否要登入 | 不用 | 要登入你的 Google 帳號 |
- 前端畫面裡沒有任何金鑰或權杖。所有寫入都送到後端，由後端檢查「登入者的 Email 是否等於你」才執行。

兩個網址要記清楚：**自己用編輯網址，分享給別人用讀取網址。**

## 2. 建立後端（Apps Script）

1. 用你的 Google 帳號開啟 https://script.google.com ，按「新專案」。
2. 左上角把專案名稱改成 `Vault`。
3. 左側「檔案」裡有一個 `Code.gs`：把裡面內容**全選刪光**，貼上套件裡 `後端/Vault_all.gs` 的**全部內容**，按存檔（Ctrl＋S）。
   - 檔案很大（約 140 KB），貼上需要幾秒。如果編輯器卡住或拒絕，換 Chrome 再試一次。
4. 上方函式下拉選單選 `setupVault`，按「執行」。
5. 第一次會要求授權：
   1. 按「審查權限」，選你的帳號。
   2. 出現「Google 尚未驗證這個應用程式」：按左下「進階」→「前往 Vault（不安全）」。這是你自己的專案，所以 Google 才會這樣提醒。
   3. 看完權限（Drive、試算表）按「允許」。
6. 執行完成後，到 Drive 會看到 `Vault/` 資料夾與「Vault 索引」試算表。

> 時區：預設用你帳號的時區。要改請到專案設定（齒輪）→ 時區。

### 選擇性：先放示範資料
函式選 `devSeed` 執行，會產生 4 則示範筆記；執行 `devSelfCheck` 可跑一次自我檢查（記錄最後一行應顯示 0 項失敗）。示範資料想清掉，直接在網頁裡刪即可。

## 3. 貼上前端並建立兩個部署

### 3.1 貼上前端
1. 左側「檔案」旁按「＋」→「HTML」。
2. 檔名輸入 `index`（不要加 `.html`），按 Enter。
3. 把預設內容全選刪光，貼上 `前端/index.html` 的全部內容（約 600 KB），存檔。

### 3.2 建立兩個部署
右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」。做兩次：

| | 讀取部署 | 編輯部署 |
| --- | --- | --- |
| 說明（隨意） | 讀取 | 編輯 |
| 執行身分 | **我** | **存取網頁應用程式的使用者** |
| 誰可以存取 | **任何人** | **擁有 Google 帳戶的任何人** |

每建立一個就把「網頁應用程式網址」複製存起來（結尾是 `/exec`）。

### 閱讀／編輯模式（擁有者）
- 頁首有一顆「👁 閱讀中／✎ 編輯中」按鈕。**預設是閱讀中**：新增、上傳、備份、編輯、刪除、編輯主題都會收起來，畫布也不能拖動、雙擊改字，所以平常翻看不會誤改。
- 要改東西時按一下切到「編輯中」；開著的畫布會直接變成可編輯。選擇會記在這個瀏覽器，下次開啟維持上次的模式。
- 畫布有沒儲存的修改時切回閱讀會先問你，確定才會放棄修改。
- 訪客沒有這顆按鈕，永遠唯讀。這只是介面層的保護，真正的權限仍由後端判斷。

### 寬螢幕版面與書櫃
- 電腦寬螢幕時，版面會隨螢幕左右擴張（列表、畫布、編輯器都用得到整個寬度）；閱讀筆記時標題與內文維持舒適的窄欄並**置中**。
- **閱讀字級**：筆記頁右上的「A−／A+」可放大縮小內文（欄寬跟著變），也可在「設定 → 閱讀字級」調整或還原；預設 100%，選擇記在這個瀏覽器。
- **書櫃預設收成左邊的小條**：點左邊的「☰」圓角按鈕，會以浮動面板展開（不推擠內容）；選了主題、點旁邊空白處或按 Esc 會自動收起。
- 面板最上面的「📌 固定展開」可讓書櫃回到左側欄；「« 收成側邊」再收起。選擇會記在這個瀏覽器。
- 手機與窄螢幕完全不受影響：書櫃仍摺疊在上方，編輯器是「編輯／預覽」切換。

### 分類頁簽與排序
- 首頁多了「**分類**」頁簽（列表｜分類｜圖庫｜日曆）：依分類列出主題卡片（筆記數、最近更新日），分類可收合，預設只展開第一個，不用一次看到全部筆記。點卡片進入該主題。預設仍是「列表」。
- **擁有者在「編輯」模式**：分類標題與主題卡片旁有 ↑↓，調整後立即儲存；沒排過的依標題排在後面，「未分類」永遠最後。編輯模式才會顯示還沒有筆記的空主題。
- **書櫃用同一份順序**，在分類頁簽排好，書櫃就跟著變。
- 訪客只看到公開的分類與主題，順序相同；私人分類名稱不會出現。
- 順序存在後端設定（Script Properties 的 `VAULT_ORDER`），不在備份 ZIP 內；重建環境後重新排一次即可。

### 畫布嵌入 HTML 與網頁
- **HTML 檔**：畫布「＋ 新增 → HTML 檔」選檔（或直接把 .html 拖進畫布），上限 500 KB。卡片一開始只顯示標題與「▶ 載入 HTML」，按了才顯示；**預設只靜態顯示，不執行腳本**。適合做成 HTML 的類筆記。
- 需要腳本的頁面（互動圖表、小工具）：選取卡片，在右側勾「允許執行腳本」。腳本在隔離環境執行，讀不到 Vault 的資料；只在你信任這份 HTML 時開啟。開啟後才允許頁面內的「下載」按鈕與 alert／確認視窗。
- **做成 HTML 時請注意**：Vault 只存**單一檔案**，所以頁面不能引用旁邊的檔案（例如 `<script src="./chart.umd.js">`），請改成 https 的 CDN 網址，或把程式碼直接貼進 HTML 裡（上限 500 KB）。另外沙箱內不能用 localStorage／sessionStorage／IndexedDB（用了要包 try/catch）。分頁切換、圖表、匯入檔案都需要先勾「允許執行腳本」。
- **嵌入網頁**（GitHub Pages、雲端網頁）：連結卡片選取後勾「嵌入網頁」，按「▶ 嵌入網頁」才連線。只收 https。有些網站不允許被嵌入（畫面空白），請按卡片上的「↗」另開分頁。
- **像開檔案一樣開啟**：在 HTML 卡片上**雙擊**、或按卡片上的「↗」，會在新分頁開成完整頁面（沙箱規則與卡片內相同）；**右鍵**（手機長按）可選「在新分頁開啟」或「下載 .html」。新分頁的網址是暫時的，關掉就失效，要分享請用公開畫布。
- 為了不卡：同時最多載入 3 個，載入第 4 個時最舊的會收回成按鈕；卡片預設不接收滑鼠（拖曳、縮放畫布不會被卡住），要在卡片內捲動或點擊時按「互動」。
- 簡報與 PNG／SVG 匯出只顯示標題，不渲染內容。HTML 檔會進備份 ZIP 與還原；訪客在公開畫布上看得到，同樣要按「載入」。

### 草稿
- 只是點開編輯器看看、沒改任何東西，**不會留下草稿**；改回原樣草稿也會自動消失。
- 新增筆記只會保留**一份**未完成草稿，再按「新增」會接著寫，不會越積越多。
- 30 天沒動的草稿會自動清除；「設定 → 草稿」可看目前數量並一次「全部清除」。

### 像 Obsidian 的寫作手感
- **`[[` 連結自動完成**：編輯筆記時打 `[[` 再打幾個字，會跳出相符的筆記清單（↑↓ 選、Enter 或 Tab 插入、Esc 關閉）。標題不存在時，清單最後一項「＋ 建立新筆記」會當場建立同主題的新筆記並插入連結。
- **Ctrl+K 快速切換**（頁首也有「⌕ 快速切換」按鈕，手機用這個）：輸入關鍵字找筆記、主題、畫布，也能執行「新增筆記、切換閱讀／編輯模式、開啟設定」。訪客只搜得到公開內容。
- **即時預覽**：編輯器預設左寫右看；窄螢幕改成「編輯／預覽」切換；也可選「只編輯」。選擇會記住。
- **文字卡轉成筆記**：畫布上選一張文字卡，右側按「轉成筆記」。會立即在同主題建立一則筆記（標題取卡片裡第一個標題或第一行），卡片原地換成筆記卡，連線與群組歸屬不變；記得再按畫布的「儲存」。

### 全螢幕與手機橫向
- 畫布按「全螢幕」後，標題與公開說明收起，工具列縮成一列：縮放、全螢幕、「☰ 工具」、（編輯模式的）儲存。
- 其他按鈕（簡報、搜尋、新增、排列、更多…）都在「☰ 工具」下拉裡，選完功能會自動收起，點旁邊空白處也會收起。
- 閱讀模式與訪客的畫布現在佔滿整個寬度（以前右邊會空一塊屬性欄的位置）。

### 畫布操作小抄
- 工具列：`＋ 新增`（各種卡片）、`排列`（對齊、等距、吸附開關、整理排版）、`更多`（預覽圖、分享、匯出入、刪除畫布）。
- 拖曳卡片會自動對齊附近卡片，按住 Alt 暫時不吸附。
- 選 2 張以上可對齊，3 張以上可等距。
- Ctrl+C／X／V 複製剪下貼上（可跨畫布、可與 Obsidian 互貼）；Ctrl+D 複製一份；直接貼上網址會變成連結卡。
- Ctrl+F 搜尋畫布上的卡片，Enter 跳下一個。
- 選一張卡片，四邊會出現小圓點：點一下在旁邊新增卡片並連線，拖到另一張卡片就連線，拖到空白處就在那裡新增。
- `＋ 新增 ▾ → 手繪`：用筆畫圖，完成後變成一張 SVG 圖片卡。
- 文字卡可在右側調整字的大小。
- `＋ 新增 ▾ → 圖片`：選 PNG／JPG／WebP（可多選）；也可以直接 Ctrl+V 貼上截圖，或把圖片檔拖進畫布。圖片會先自動縮到最長邊 1600 px 並轉成 WebP 再上傳，存在你 Drive 的 assets 資料夾。檔案偏大只會提醒，不會擋；真正的上限是 5 MB。
- 圖片的公開規則：只有「公開主題的畫布」放了這張圖，訪客才看得到。
- 工具列「簡報」：依群組一頁一頁放大（沒有群組就逐張卡片，順序是由上到下、左到右）；←／→（或空白鍵）換頁，Esc 離開。訪客也能用。
- `更多 ▾ → 匯出 PNG／SVG 圖片`：把整張畫布存成圖片；先選取一些卡片再匯出，就只匯出選取的部分。圖片是白底、固定配色，不含任何外部資源。
- 選一個群組，右側有「轉成大綱筆記」：把群組裡的卡片依位置排成 Markdown 清單，開成新筆記草稿（不會自動存檔；筆記卡會變成 `[[筆記id]]` 連結）。
- 筆記頁底部按「出現在哪些畫布？」，列出放了這則筆記的畫布（訪客只會看到公開主題的畫布）。
- 選一條連線，右側可調整文字大小（小／中／大）與位置（靠起點／置中／靠終點），預設是中、置中。
- 圖片也會進 ZIP 備份（以 png／jpg／webp 實體檔存放）與每月備份；GitHub 靜態站暫不輸出圖片卡。

### 分享主題與畫布
- 主題頁按「分享連結」：得到 `讀取網址?topic=<主題id>`。
- 畫布頁工具列按「分享連結」：得到 `讀取網址?topic=<主題id>&board=1`，訪客打開會直接進畫布（私人筆記的卡片會被拿掉）。
- 主題必須是公開的，訪客才打得開；私人主題按分享會提醒你。

### 3.3 設定分享用網址
1. 左側齒輪「專案設定」→ 往下找「指令碼屬性」→「新增指令碼屬性」。
2. 屬性 `PUBLIC_URL`，值填**讀取網址**。存檔。
   這樣筆記裡「分享連結」才會指到唯讀版，不會洩漏編輯網址。

## 4. 第一次使用

1. 瀏覽器開**編輯網址**，登入你的帳號。右上角應顯示「擁有者」。
   - 第一次可能再跳一次授權，同樣按允許。
2. 開**讀取網址**（最好用無痕視窗）：右上應顯示「訪客・唯讀」，而且看不到任何私人筆記。
3. 回編輯網址，按「上傳」，把 `範例資料/` 裡的 `note_a.md`、`note_b.md` 傳上去試試。

> 手機：同樣開編輯網址即可。手機建議用來閱讀與寫文字筆記；畫布在手機上預設只能看、平移縮放，不能編輯。

## 5. 日常操作

**新增筆記**：右上「新增」，填標題、內文（Markdown）、主題、日期、標籤，按「儲存」。內文用 `[[筆記標題]]` 連到其他筆記。

**上傳**：
- 單檔或多檔：`.md`（筆記）、`.svg`（圖）。
- 整個資料夾：資料夾名稱會當成「主題」，裡面的 `.md` 與 `.svg` 一起匯入。筆記內 `[[標題]]` 與 `![](圖.svg)` 的相對路徑會自動對上。
- 檔案會被指定新的 id；原檔名記在筆記的 `source`。

**主題與書櫃**：左側書櫃依主題分類。「新增主題」可設名稱與預設公開狀態。擁有者的書櫃每個主題旁會標示「公開」（實線）或「私人」（虛線），那是主題的預設公開狀態；訪客看不到這些標籤。

**三種檢視**：列表、圖庫（用 SVG 封面）、日曆（雙擊某天可新增筆記）。

**畫布**（每個主題一張）：
- 單擊卡片放大，雙擊開啟筆記；右上有全螢幕。
- 可放筆記卡、連結（YouTube 可嵌入）、便利貼、群組（可巢狀、可收合）、連線（名稱、方向、顏色、實線／虛線）。
- 筆記卡會顯示日期、標籤與封面縮圖。「＋圖片」可放入你筆記裡用到的 SVG。
- **連結預覽**：「＋連結」貼上 https 網址並保持勾選「加入後擷取網頁預覽」，Apps Script 會連到該網址一次，把標題、描述、封面圖網址存進卡片（不會再自動更新，可在右側面板「重新擷取預覽」）。第一次使用請先在編輯器執行 `authorizeP5`。
- **預覽圖開關**：工具列「預覽圖：開／關」，預設關閉。關閉時畫布不會連任何外部網站；開啟後才會載入 YouTube 縮圖、圖片網址與網頁封面（對方網站看得到你的 IP）。每位檢視者各自決定。
- **整理排版**：工具列「整理排版」可把筆記卡片排成網格、依標籤分組或依月份排成時間軸，也可順便放入本主題還沒上畫布的筆記；有選取卡片時只整理選取的；可復原，按「儲存」才寫入。
- 「匯出」得到 `.canvas`（Obsidian 可開）；「匯入」會**取代目前畫布**，但在你按「儲存」前不會寫入雲端，且可復原。「刪除畫布」會把該主題的畫布檔移到 Drive 垃圾桶並清空畫面（要確認；主題與筆記都不會被刪，可從垃圾桶還原檔案）。

**批次修改**：書櫃列表選多則，可一次改主題、公開狀態、標籤，或刪除。

**搜尋**：搜尋框支援中文分詞、標籤、主題；英文介面用英文操作。

**設定**：配色（10 組＋自訂）、語言（繁中／英文）。

## 6. 公開與私人的規則

1. 筆記 front matter 有 `public: true/false`，以它為準。
2. 沒填就看主題的「預設公開」。
3. 主題也沒設就是**私人**。
4. SVG：只要被公開筆記（內文或封面）引用，或在公開主題的畫布上，就是公開；只被私人筆記引用的 SVG，訪客取不到，連「存在與否」都無法區分。
5. 畫布隨主題：私人主題的畫布，訪客完全看不到；公開主題的畫布，訪客看到的版本會**拿掉私人筆記的卡片**。
6. 筆記裡指向私人筆記的 `[[連結]]`，訪客看到「（未公開的筆記）」。

**發布前檢查**（擁有者專用，編輯網址右上角的「發布檢查」按鈕）：
- 「訪客視角預覽」：看到的就是訪客看到的。
- 「個資掃描」：掃出所有公開筆記裡的 Email、電話、身分證字號、地址，只警告、不阻擋，可直接改成私人。

把私人主題改成公開時，若底下有未明確設定公開狀態的筆記，系統會先請你確認。

## 7. 備份與還原

### 7.1 備份（存在你的 Drive）
1. 編輯網址右上「同步與備份」（手機在「選單」裡）。
2. **第一次**：到 Apps Script 編輯器，函式選 `authorizeP5`，執行並授權（新增「外部連線」與「計時器」權限）。之後才能用自動備份。
3. 按「立即備份」。大型 Vault 會分段進行，頁面會自動續跑。
4. 完成後顯示檔名、各項數量與「已核對」（程式會解壓檢查）。ZIP 在 Drive 的 `Vault/_backup/`。
5. 按「每月自動備份」開啟：每月 1 日凌晨約 3 點備份，預設保留最近 12 份。

**建議第一次手動確認**：下載 ZIP 解壓，裡面應有 `notes/`、`assets/`、`topics/`、`boards/`、`manifest.json`。

### 7.2 還原
1. 「備份」頁（不是「同步與備份」）選「還原」，選擇 ZIP。
2. 先看**還原預覽**（新增幾則、覆蓋幾則），確認後執行。
3. 如果備份頁提示「有 N 個檔案讀不到」，代表有筆記檔已被你從 Drive 刪除但索引還留著：到 Apps Script 執行 `devRebuild` 即可清掉。

## 8. 選配：靜態網站（GitHub＋Cloudflare Pages）

不需要就整段略過，其他功能不受影響。用途：把公開內容變成固定網址、載入快、可被搜尋引擎收錄的獨立網站。網站只有 `/zh/` 與 `/en/`，沒有登入與編輯。

### 8.1 建 GitHub 私人倉庫
1. github.com → 右上「＋」→ New repository，名稱例如 `vault-site`，選 **Private**，勾「Add a README file」（倉庫必須先有一次提交）。

### 8.2 建一把只能寫這個倉庫的權杖
1. 頭像 → Settings → 最下面 Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token。
2. 到期日選最長；Repository access 選 **Only select repositories**，只選上面那個倉庫。
3. Permissions → Repository permissions → 加入 **Contents**（可用搜尋），改成 **Read and write**，其他不加。
4. Generate token，複製 `github_pat_…`（只顯示一次）。

### 8.3 設定指令碼屬性
Apps Script「專案設定」→ 指令碼屬性，新增：
- `GITHUB_TOKEN`：剛才那串
- `GITHUB_REPO`：`你的帳號/vault-site`
- 選填：`GITHUB_BRANCH`（預設 main）、`GITHUB_DIR`（預設 content）

權杖只存在這裡，前端看不到。

### 8.4 放網站程式
把 `選配_靜態站/` **裡面的檔案**（`build.js`、`lib/`、`package.json`、`site.config.json`、`README.md`）放到倉庫根目錄：倉庫頁面 Add file → Upload files，拖進去，Commit。
`site.config.json` 可改站名（`siteName`）、副標（`tagline`）、預設語言（`defaultLang`）。

### 8.5 第一次同步
1. 編輯網址「同步與備份」→ 網站同步區：按「**預覽變更**」，看將新增幾個檔案；沒問題按「**立即同步**」。
2. GitHub 倉庫會多出 `content/`。只會推送訪客看得到的內容。
3. 沒有變動時不會產生新提交（省建置次數）。可開「每日自動同步」（凌晨約 4 點）。

### 8.6 接上 Cloudflare Pages
1. 註冊 cloudflare.com（免費）。左側「Workers 和 Pages」→「建立應用程式」→ 找小字「Looking to deploy Pages? **Get started**」→ Import an existing Git repository。
2. 授權 GitHub。倉庫清單若搜不到你的私人倉庫：按畫面下方「Cloudflare Pages」藍色連結，到 GitHub 的授權頁選 Only select repositories，把該倉庫加進去，回來重新整理。
3. 建置設定：Build command `node build.js`；Build output directory `dist`；環境變數 `SITE_URL`（例如 `https://專案名.pages.dev`）。必要時加 `NODE_VERSION=20`。
4. Save and Deploy，一兩分鐘後開 `https://專案名.pages.dev/zh/`。

### 8.7 注意
- 靜態網站是「訪客視角的快照」，公開內容改了要再同步一次才會更新。
- 沒設定 `lang` 的筆記歸「預設語言」。
- 靜態畫布是簡化的唯讀版（沒有影片嵌入）。
- 細粒度權杖會到期，過期時同步會顯示 401 訊息，重新產生並更新 `GITHUB_TOKEN` 即可。

## 9. 額度與限制

以下數字會變動，**請以官方文件為準**：
- Apps Script 配額：https://developers.google.com/apps-script/guides/services/quotas
- GitHub Git Data API：https://docs.github.com/en/rest/git/trees
- Cloudflare Pages 限制：https://developers.cloudflare.com/pages/platform/limits/

實務上要知道：
- 單次後端執行有時間上限（約數分鐘），所以備份與同步都做成分段。
- 免費 Cloudflare Pages 每月有建置次數上限，所以「沒變動就不提交」很重要。
- 公開網址流量大時，讀取部署也受 Apps Script 每日額度限制；流量大的話建議用靜態網站。
- 筆記大小與 SVG 大小有上限，超過時儲存會被拒絕並說明原因。
- Google 試算表索引的列數有上限，個人讀書筆記規模通常用不到。

## 10. 更新到新版

1. 把新的 `Vault_all.gs` 貼進 `Code.gs`（全選取代）、新的 `index.html` 貼進 `index`。
2. 「部署」→「管理部署作業」→ 各部署的鉛筆 → 版本選「新版本」→ 部署。**讀取與編輯兩個都要做**，網址不會變。
3. 若更新說明寫了「需執行 setupVault」才執行（補欄位用，不會清掉資料）；若有新增權限，照說明執行 `authorizeP5`。

## 11. 疑難排解

| 狀況 | 原因與處理 |
| --- | --- |
| 開網頁顯示「尚未完成設定」 | 還沒執行 `setupVault`，或在別的專案執行了。在這個專案執行一次 |
| 開網頁說缺少 `index` | HTML 檔名要是 `index`（沒有副檔名） |
| 編輯網址右上顯示「訪客」 | 部署的「執行身分」要是「存取網頁應用程式的使用者」；或用了別的 Google 帳號登入。登出後用建立專案的帳號 |
| 改了程式但畫面沒變 | 忘了更新**兩個部署**的版本，或瀏覽器快取：強制重新整理 |
| 編輯器貼不進大檔案 | 換 Chrome；或把檔案分兩段貼，仍不行就先停止其他分頁 |
| 儲存時出現「無法完成」 | 你不是擁有者帳號，或用的是讀取網址 |
| 備份說「有 N 個檔案讀不到」 | 筆記檔被你從 Drive 刪了但索引還在。執行 `devRebuild` |
| 備份失敗，說 ZIP 驗證不過 | 壓縮功能沒保留資料夾結構。請把錯誤訊息回報，暫時改用「備份」頁的完整 ZIP 匯出 |
| 同步顯示 401／403 | 權杖過期、倉庫名打錯，或權杖沒勾 Contents 的 Read and write |
| 同步顯示「找不到倉庫」 | `GITHUB_REPO` 要寫 `帳號/倉庫名`，權杖要涵蓋該倉庫 |
| 網站是空的「目前沒有內容」 | 還沒按「立即同步」，或同步後 Cloudflare 還在重新建置 |
| Cloudflare 找不到私人倉庫 | 要在 GitHub 授權頁把倉庫加進 Cloudflare Pages 應用程式的存取清單 |
| 網站有，但缺某則筆記 | 該筆記是私人的，或所屬私人主題未公開 |
| 手機無法編輯畫布 | 預設設計如此（手機可閱讀、平移縮放）。開發者可改 `FEATURES`（見 13 節） |
| 空白頁、或想還原誤刪的筆記 | 先到 Drive 垃圾桶還原檔案，再執行 `devRebuild` |

資料壞掉的最後保險：Drive 裡的 `notes/*.md` 是純文字，直接可讀；`devRebuild` 會掃描它們重建索引。

## 12. 設定速查表

**指令碼屬性**（Apps Script → 專案設定 → 指令碼屬性）

| 名稱 | 誰設定 | 說明 |
| --- | --- | --- |

| `GITHUB_REPO` | 你（選配） | `帳號/倉庫` |
| `GITHUB_BRANCH`、`GITHUB_DIR` | 你（選配） | 預設 `main`、`content` |

**網址**：
- 編輯網址：自己用。

## 13. 安全與隱私說明

- 擁有者判斷只看「登入者 Email ＝ `OWNER_EMAIL`」；兩邊任一為空一律當訪客。
- 讀取網址上的 REST 讀取一律以訪客處理，不論你有沒有登入。
- 前端沒有金鑰；GitHub 權杖只在指令碼屬性。
- SVG 一律用 `<img>` 顯示（腳本不會執行），上傳與同步時還會清除 `script`、事件屬性、`foreignObject`、外部連結與危險樣式。
- 靜態站推送的只有訪客看得到的內容；私人內容不離開 Drive。
- `開發者/SECURITY_AUDIT.md` 列出實際跑過的 58 項檢查。

**給想自己改的人**：`開發者/原始碼/` 內含前端與後端原始碼與建置程式。前端 `FEATURES = { mobileEdit: true, canvasTouchEdit: false }` 控制手機可否編輯；改完執行 `node frontend/build.js` 與 `node p1/tests/build_bundle.js` 即可重新產出兩個單檔。需要 Node 18 以上。


## 清理未使用檔案
畫布刪掉圖片卡或 HTML 卡時，檔案本身仍留在 Drive 的 assets 資料夾（為了復原與多張畫布共用）。檔案多了可以清理：

1. 設定 → 「清理未使用檔案」→ 按「掃描」。
2. 清單只會列出**所有畫布（含私人）都沒用到**、且建立超過 7 天的圖片與 HTML 檔；預設全選，可取消勾選。
3. 按「移到垃圾桶」。檔案進入 Google Drive 垃圾桶，30 天內可以救回。

安全設計：掃描看的是全部畫布，不是目前這一張；任何一張畫布讀取失敗就整個中止；移除時後端會重算一次，過期的清單不會誤刪現在還在用的檔案。
